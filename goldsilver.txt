LIVE GOLD AND SILVER PRICES
==========================

How the feature works
---------------------
The gold and silver ticker displays market reference prices on the website.
When a page with the ticker loads, its browser-side JavaScript requests the
app's own endpoint:

    GET /api/metals

The Flask app then requests recent chart data from Yahoo Finance for these
futures symbols:

    Gold:   GC=F
    Silver: SI=F

The request uses a one-day period with one-minute chart intervals. The app
chooses the latest available price and calculates its percentage change from
the previous close. It returns the gold and silver prices, percentage changes,
currency, and a UTC update timestamp as JSON.

The browser formats the prices as US dollars and displays the percentage
changes and the time the response was updated. It requests the data again once
per minute. The browser request disables its cache, so it asks the app for a
fresh response each time. The app, in turn, fetches current data from Yahoo
Finance when handling the request; no API key is configured in this
implementation.

What the prices mean
--------------------
GC=F and SI=F are gold and silver futures references, not quotes for a
particular physical bar or coin. They do not include product premiums, shipping,
taxes, or other transaction costs, and they are not a guaranteed buying or
selling price from FK Physical LLC. Confirm the actual product, weight, purity,
availability, premium, and total price directly before making a purchase.

Availability and limitations
----------------------------
- The displayed figures depend on Yahoo Finance returning usable market data.
  The data may be delayed, unavailable, or different from a physical bullion
  dealer's transaction price.
- The live endpoint currently returns zero-valued prices if its upstream
  request fails. A zero can therefore be mistaken for a real value; treat it
  as a possible data error if the ticker appears unavailable or incorrect.
- The update timestamp is generated by the app when it creates the response.
  It indicates when the app responded, not necessarily the exchange's quote
  time.
- The site refreshes about once per minute, but this does not guarantee that
  the underlying market data itself is updated every minute.

Related historical-data endpoint
-------------------------------
The app also provides:

    GET /api/metals/performance?range=1m
    GET /api/metals/performance?range=6m
    GET /api/metals/performance?range=1y
    GET /api/metals/performance?range=5y

This endpoint returns historical gold and silver futures price points using
Yahoo Finance chart data. Unsupported range values receive HTTP 400; upstream
or incomplete-data errors receive HTTP 502. Successful responses are marked
cacheable for 15 minutes. Although chart JavaScript exists in the project, the
current Gold & Silver page does not provide the chart elements and API URL it
expects, so the historical chart is not currently displayed there.
