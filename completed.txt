3. API inventory and live metals prices
---------------------------------------
The app's JSON APIs and their upstream data source are:

- `GET /api/metals` — app-owned live gold and silver ticker endpoint. The
  browser requests it when the page loads and every 60 seconds thereafter.
  The Flask server requests Yahoo Finance chart data for gold futures symbol
  `GC=F` and silver futures symbol `SI=F` using a 1-day range and 1-minute
  interval. It returns each metal's latest available market price, percentage
  change from the previous close, and currency, plus a UTC `updated_at`
  timestamp. The ticker formats and displays these values in the shared site
  footer/header area. Browser caching is disabled for these requests.
- Yahoo Finance upstream chart API —
  `https://query1.finance.yahoo.com/v8/finance/chart/{symbol}`. This is the
  external source used by both metals endpoints; it is called server-side, so
  the browser only talks to this app's `/api/metals` endpoint. Prices are
  futures-market reference values, not a quote or guaranteed transaction price
  for physical bullion. The endpoint does not require an API key in the current
  implementation.
- `GET /api/metals/performance?range={1m|6m|1y|5y}` — app-owned historical
  performance endpoint. It requests the same Yahoo Finance futures symbols with
  a range/interval selected by the query: 1 month or 6 months at daily
  intervals, and 1 year or 5 years at weekly intervals. It returns timestamped
  gold and silver price arrays as JSON, rejects unsupported ranges with HTTP
  400, reports upstream/data failures with HTTP 502, and sets a 15-minute
  public cache header on successful responses. A frontend chart script is
  included, but its required chart container and API URL are absent from the
  current Gold & Silver template, so this endpoint is not currently used to
  render a chart.

No other third-party data, payment, CRM, or email API integration was found.
Contact submissions are validated locally and handed off through a `mailto:`
link rather than sent to an API. Google Fonts are loaded as external stylesheets,
not consumed as app APIs.
